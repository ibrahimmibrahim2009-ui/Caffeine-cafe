# Caffeine Cove 
### An experimenta wesbite simulating special coffee profficient in making coffee and other related drinks like Espresso, Cappuccino, Americane, etc. The website contains many sections that have some similarities. Each section contains its specific aim, like Menu section, where you can see the different drink types, info about it, prices, and choose of them. In the project, i used my hand-made framework and added the repeated codes i used ot it, in order to increase its capacity and validity. The project is fully responsive, where you can use it on mobile, ipand, or laptop.
